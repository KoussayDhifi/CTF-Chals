# CTF Challenges

A collection of Capture The Flag (CTF) challenges I've developed for cybersecurity competitions, workshops, and hands-on security training.

The repository showcases my work in offensive security, challenge development, and practical vulnerability research, with a focus on building challenges that encourage technical exploration and creative problem-solving.

## About

I'm a software engineering student and cybersecurity enthusiast focused on web exploitation, offensive security, and security education. Beyond playing CTFs, I enjoy designing challenges that help others understand how vulnerabilities work and how they can be exploited.

My challenges have been developed for events organized by **Securinets FST** and other student cybersecurity communities.

## What's Inside

This repository contains challenge source code, supporting files, and other development artifacts. Each challenge may have its own implementation, dependencies, and deployment requirements.

Depending on the challenge, the material may include:

* Vulnerable applications and exploitation scenarios.
* Challenge source code and supporting assets.
* Containerized environments and deployment configurations.
* Challenge-specific instructions and testing resources.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/KoussayDhifi/CTF-Chals.git
cd CTF-Chals
```

Explore the individual challenge directories and follow the instructions provided with each challenge. Requirements and setup steps may vary depending on the implementation.

If a challenge includes a `Dockerfile` or Docker Compose configuration, review it before building or running the environment.

## Disclaimer

These challenges are intended for **educational purposes and authorized security testing**. Run vulnerable applications only in isolated environments that you control or have explicit permission to use.

Some challenges intentionally contain security weaknesses. Do not expose them to public networks unless the environment has been configured and secured appropriately.
